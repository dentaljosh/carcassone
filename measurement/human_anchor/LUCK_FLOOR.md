## Headline

- **Deck-luck share of margin variance: ~0.14** (seat-margin ICC across near-equal agent pairs, n-weighted over 4350 deck-pairs).
- **Per-game margin SD: sigma_game ~ 22.2 points** (seat-swap paired-avg SD sigma_pair ~ 14.5 points).
- **Seat-swap deck-pairing variance-reduction factor: ~0.86** of the naive per-game variance (removes first-player + seat luck).

## Required games to power a superhuman claim

A superhuman claim needs the agent's win-rate vs a strong human to have a 95% CI lower bound > 0.5. Games needed at plausible TRUE win-rates:

| true wr | implied edge (pts) | n (naive per-game) | n (seat-swap paired) |
|--------:|-------------------:|-------------------:|---------------------:|
| 0.52 | +1.1 | 2398 | 1309 |
| 0.55 | +2.8 | 381 | 209 |
| 0.60 | +5.6 | 93 | 52 |

_'implied edge' = mean point margin an agent needs to win at that rate given sigma_game; naive n from the binomial CI; paired n from the seat-swap paired-margin test (SE = sigma_pair/sqrt(D), 2 games/deck-pair)._

## Implied ceiling win-rate vs an expert

Deck luck caps the win-rate even under perfect play: with an irreducible per-game margin SD of ~22.2 pts, a true point-edge of `e` yields win-rate `Phi(e/sigma_game)`:

| true edge (pts) | ceiling win-rate |
|----------------:|-----------------:|
| +3 | 0.554 |
| +5 | 0.589 |
| +8 | 0.641 |
| +10 | 0.674 |
| +15 | 0.750 |
| +20 | 0.816 |

The strongest agent on disk (`exact_4_clair__vs__heur3200__n100_v28`) beats the strong-search expert proxy at **0.568** (margin +3.9 pts). Humans are likely weaker than that search proxy, so the true edge — and ceiling win-rate — vs a human expert is *at least* this, but the deck floor keeps it well below 1.0 (see table).

## Method + caveats

- **Variance decomposition:** each archive is one agent pair played on N decks x 2 seatings (same shuffled deck, seats swapped; identical `deck_hash`). `luck_share` = Pearson corr of the seat-0-minus-seat-1 score margin between the two seatings (the ICC of the deck on the seat margin); the residual `1 - luck_share` is play divergence + agent skill + who's in seat 0. `sigma_game` = SD of the agent's per-game point margin; `sigma_pair` = SD of the agent's seat-swap-averaged per-deck margin (deck seat-luck differenced out).
- **Why near-equal pairs for the headline:** a strong-vs-weak pair inflates the within-pair (skill) variance and *understates* the luck share, so the deck-luck fraction is read off near-equal pairs (heur ladder rungs + v29 self-play arms).
- **Proxy caveat:** these are agent-vs-agent games, not agent-vs-human, so the luck share is a proxy — a human's higher move variance would ADD to the non-deck (play) variance, *lowering* the luck share and *raising* the games needed. Treat the naive-n column as an optimistic floor.
- **Recommendation:** run the human protocol as **seat-swap deck-pairs** (each deck played twice, seats swapped, scoring the agent's averaged margin) — it removes the first-player + seat luck and cuts the games needed by ~14% vs a naive per-game win count.
