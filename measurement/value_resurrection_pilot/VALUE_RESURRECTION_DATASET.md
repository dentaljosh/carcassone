## Per-child labels

For each canonical child (id-deduped, lowest action id per unique child state — matching the labeler):

| Label | How | POV |
|---|---|---|
| `oracle_q` (teacher) | `action_q[a]` from the h6400 probe | root-player |
| `leaf_q` (v2.9 leaf) | `tanh(virtual_score_v2(child.state, root_player, cfg_v29)/15)`; terminal child → `clip(true score sign)` | root-player |

### ⚠️ POV correction (important — differs from `forced_move.py`)

In this engine a **TILES-phase action does NOT flip `current_player`** (place tile → meeple phase,
same player). Verified: **1816/1816** enumerated children keep the mover. So the
`forced_move.py` convention `L0 = -tanh(vs2(child, child.current_player)/15)` ("negate for
opponent-to-move") is **wrong for these states** and yields a sign-flipped, anti-correlated leaf
(τ = −0.90). The pilot evaluates every child from the **fixed root-player seat**:
`leaf_q = tanh(vs2(child, root_player)/15)` — turn-structure-robust and matching the teacher's own
`action_q` convention. Empirically validated: τ(leaf_q, h6400) = **+0.90** (vs −0.90 flipped).
*(Side note: this implies `forced_move.py`'s I6 "leaf value-blind" numbers in the b99c9ed autopsy
were likely sign-inverted on same-player TILES roots — i.e. the v2.9 leaf ranks the teacher's child
correctly far more often than I6 reported. This **reinforces** the Decision-B prior; flagged, not
actioned.)*

## Coverage

- **Per-child Q completeness:** 7,250 / 10,067 roots have h6400 Q for **every** legal child
  (`|action_q| == legal_n`); 2,817 are partial (h6400 at 6400 sims left the worst children unvisited →
  effectively low-Q). The pilot ranks/scores over the **teacher-visited** subset (≥2 children),
  which is *favourable to the leaf* (it is not penalised for picking a child h6400 pruned).
- **Phase coverage (the join):** endgame 3,358 · pre_endgame 2,238 · midgame 2,238 · late_mid 1,120 ·
  opening 1,113. The narrow pilot slice (pre_endgame + endgame) = **5,596** sets.

## Stage-4 training dataset — `rows.npz`

Built by `scripts/rod_v2/value_resurrection/dump_dataset.py` (replay + encode + label, CPU-parallel)
→ `/mnt/c/carc-shared/value_resurrection/dataset_v29_h6400/rows.npz`:

| key | shape | dtype | meaning |
|---|---|---|---|
| `child_obs` | (M, C, W, W) | f16 | `encode_board(child.state, root_player, child.offset)` |
| `child_scalars` | (M, 12) | f16 | `encode_scalars(..., include_farm=True)` |
| `oracle_q` | (M,) | f32 | h6400_v2.9 root-POV Q (the teacher target) |
| `leaf_q` | (M,) | f32 | v2.9 leaf root-POV value (for the offline combined-ranker gate) |
| `group_id` | (M,) | i32 | sibling set id (one per root) |
| `game_seed` | (M,) | i64 | for leakage-safe split |
| `ply` / `phase` / `q_gap` | (M,) | i16 / U12 / f32 | provenance + slicing |

`M` ≈ teacher-visited children summed over 10,067 groups (≈160k; exact in `meta.json`).
**Leakage control:** train/val/test = 70/15/15 split **by `game_seed`** (md5 hash) — all children of a
root, and all roots of a seed, stay in one split. A-leg only; `pool_B.jsonl` (10,080) is held in
reserve as an independent test set (would need a fresh h6400 CPU pass).
