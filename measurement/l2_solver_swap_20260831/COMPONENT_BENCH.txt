READING NOTES

* The "already-drained" block is the UNFAIR comparison and is printed only to
  expose the trap: `apply_action` has already emptied `placed_meeples` by the
  time a terminal state exists, so the engine route's second
  `count_final_scores` is a no-op (590 ns = the clone) while the flat route
  still pays a full whole-board `decompose_into`. Read the "un-drained" block —
  both routes on a state that still carries every meeple — as the honest
  scorer contrast. It is 2.86x, not the 15.28x the perf sweep's L2 row claimed.

* An earlier capture of the same harness under the W36 sweep (loadavg ~33) gave
  2.79x with every absolute number ~1.05-1.10x inflated. The RATIO is stable
  across the contention change because the arms are interleaved; the absolutes
  are not, which is why only this quiet capture is quoted in the READOUT.

* `decompose_into` is 95.9% of the flat route (7685 / 8013). An exact-K
  terminal is the most expensive board in the game for that function — a full
  ~70-tile whole-board union-find — which is the root cause of the estimate's
  inflation: L0's 7.9-9.9x playout-scorer factor was measured on afterstates
  spanning all game phases, where `decompose_into` is far cheaper, and does not
  transfer to end-of-game boards.
